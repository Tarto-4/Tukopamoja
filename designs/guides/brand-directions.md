# ENS-Future Brand Directions

## Direction A — Legal-Tech Prestige
- Serif-forward wordmark with controlled spacing
- Crimson-gold accents on dark backgrounds
- Minimal gradients, stronger typographic authority

## Direction B — Competitive Energy
- Sharper symbol mark for game identity
- Bold geometric emblem (Q + A fusion)
- More pronounced glow for tournament moments only

## Direction C — Enterprise Minimal
- Monoline icon system for dashboard surfaces
- Reduced visual noise for admin workflows
- Color used sparingly to highlight critical actions

## UI Guidance
- Use strong contrast and readable hierarchy first.
- Keep 3D/glow effects subtle and intentional.
- Use crimson for action focus, gold for achievement states.
- Maintain consistent spacing rhythm (8pt system).
