# TUKOPAMOJA Design Workspace

This folder stores visual references and reusable brand assets used to guide UI improvements.

## Structure

- `logo/` — primary logo concepts and compact marks
- `favicon/` — favicon concepts and browser icon source
- `guides/` — brand direction notes and UI art direction
- `palette.json` — canonical color tokens

## Canonical Palette (ENS-Future)

- ENS Crimson: `#8E191E`
- Carbon Black: `#111111`
- Slate Deep: `#3A3A3C`
- Slate Light: `#636366`
- Prestige Gold: `#C9A84C`
- Off White: `#F5F5F3`

## Notes

- SVG files are source-of-truth so they can be scaled for web, mobile, and print.
- Keep logos high-contrast on dark surfaces.
- Favor geometric forms with subtle premium accents rather than heavy ornament.
