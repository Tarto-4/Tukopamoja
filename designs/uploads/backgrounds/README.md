# Uploaded Background Images

Drop your uploaded background images in this folder.

Recommended names for direct usage in UI:
- `home-bg.jpg`
- `login-bg.jpg`
- `host-lobby-bg.jpg`
- `player-lobby-bg.jpg`

Recommended format:
- `1920x1080` (or larger), JPG/WebP for photos, PNG for transparent artwork.
- Keep file sizes under `1.5MB` per image for fast loading.

After adding images, copy optimized versions into:
- `packages/web/public/designs/backgrounds/`

The web app reads background assets from the public folder.
